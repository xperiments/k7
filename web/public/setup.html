Trust this player once

xtape serves its app over HTTPS with a certificate of its own. Installing it takes a minute and no account: after this the browser treats the player as a secure site, and the app can open your card and keep its measurements offline.

Download the certificate I have already trusted it — open the app

macOS

One line in Terminal. It downloads the certificate and trusts it system-wide; the password it asks for is your own.

$ curl -sO http://xtape.local/ca.pem && sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.pem

Or by hand: open the downloaded ca.pem, choose the System keychain, find xtape local CA, open Trust, set When using this certificate to Always Trust and close the window.

Windows

One line in PowerShell run as Administrator. It downloads the certificate and puts it in the machine's trusted roots.

PS> Invoke-WebRequest http://xtape.local/ca.pem -OutFile ca.pem
PS> Import-Certificate -FilePath ca.pem -CertStoreLocation Cert:\LocalMachine\Root

Or by hand: double-click the downloaded ca.pem, choose Install Certificate, Local Machine, Place all certificates in the following store, pick Trusted Root Certification Authorities, and finish.

Linux

Chrome and Chromium read their own store:

$ curl -sO http://xtape.local/ca.pem && certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "xtape local CA" -i ca.pem

On Firefox, import ca.pem under Settings → Privacy & Security → Certificates → Authorities instead.

Restart the browser when the command has finished, then open https://xtape.local.

Phones and tablets

iOS and Android each have their own way to install a certificate profile; the player works, but the analysis app is meant for a computer. The stream needs none of this.

The stream needs no certificate

A radio or a car head unit can listen at http://xtape.local/stream — plain HTTP, no trust step, no app.
