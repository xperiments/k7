# screen_display

The screen: the panel (or the headless framebuffer), LVGL's PSRAM allocator, the
cassette view and, on the panel board, its touch controller. The public interface is
`include/screen_display.h` — `screen_display_start()` and nothing else. Everything else
is private:

- `screen_display.c` — start-up, the draw buffer, the serial dump and the task that keeps
  the cassette current.
- `lvgl_mem.c` — the `LV_USE_CUSTOM_MALLOC` backend, PSRAM first (ADR 0004).
- `cassette_view.c` — the LVGL objects, layout and touch actions; the arithmetic is
  `components/portable/cassette`. The small cream label is drawn from LVGL objects; the
  big cover is `assets/labels/glabel-full.png`, whose tape window is transparent so the
  reels show through it.
- `panel_rgb.c` — the Sunton panel adapter, compiled only for that board.
- `touch_gt911.c` — the Sunton touch adapter: a GT911 on I2C0, polled every 10 ms and
  bound to LVGL as the display's pointer. It feeds LVGL's multi-touch recognizer, so the
  view can tell a two-finger swipe from a one-finger one: a tap is next track, a
  one-finger left/right swipe is next/previous, a one-finger down/up swipe slides the
  small label in and out, and any two-finger swipe toggles the big cover.
- `assets/hub_frames.bin`, `assets/label_cover.bin` — generated by
  `tools/convert_cassette_assets.py`; the hub frames are opaque RGB565, the cover is
  RGB565A8 for its alpha window.

The panel and the headless path are two adapters behind the same interface, selected by
`CONFIG_APP_BOARD_SUNTON_8048S050C` in this component's CMake. The touch adapter is a
second, input-side adapter under the same selection: a board without a controller simply
has no pointer. A third panel promotes that selection to a `display_port` seam without
changing `screen_display_start()`.
