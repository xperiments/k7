# 05 — Compile the design's faces at the design's sizes

**What to build:** the typography a design names, compiled into the image so the panel looks like
the editor's preview — [`docs/specs/label-templates.md`](../../../specs/label-templates.md) §4.

The faces are the ones the builder embeds (Google Fonts, OFL, Latin subset): **Archivo Narrow
600**, **Barlow Condensed 700**, **IBM Plex Mono 500**, at the sizes the editor's font roles
default to — 24 px title, 64 px numeral, 18 px caption. They live as base64 inside
`resources/LVGL canvas builder.html`, which is why the same glyphs appear in the web preview and
in the LVGL one.

1. **Get the faces into `assets/fonts/`.** A small `tools/extract_builder_fonts.py` pulls each
   embedded base64 font out of the builder and writes the TTF, so the conversion is reproducible
   from the builder's own bytes rather than from someone's Downloads folder.
2. **Convert each one**: `lv_font_conv --bpp 4 --size <px> --font <ttf> --range 0x20-0x7E` (plus
   the accented range if the designs print them), committed as `font_<face>_<px>.c`, the way
   `font_jura_36.c` is.
3. **Add the rows to `assets/labels/fonts.json`** and to the app's `k_label_font[]`, which is
   ordered by the generated `label_fonts.h` (ticket 02), so a missing symbol is a compile error
   rather than a blank label.
4. **A licence notice** in `THIRD_PARTY_NOTICES` for the three OFL faces, and the licence text in
   `LICENSES/` if the OFL is not already there.

The three Jura faces already in the table stay: they are what a design can use before this
ticket's faces exist, and what the reference design wears.

## Comments

- `tools/extract_builder_fonts.py` pulls the three faces out of the builder's embedded
  base64 and writes the TTFs, so the conversion is reproducible from the builder's own bytes:
  `assets/fonts/archivo-narrow-600.ttf` (19,876 B), `barlow-condensed-700.ttf` (27,180 B),
  `ibm-plex-mono-500.ttf` (16,028 B).
- Converted at 24, 64 and 18 px with the repo's own `lv_font_conv` shape (4 bpp, no compress, the
  same range set as Jura), as `archivo_narrow_600_24`, `barlow_condensed_700_64` and
  `ibm_plex_mono_500_18`. Glyph data: 16,685 / 106,262 / 11,791 B.
- `package.json` gained `font:archivo24`, `font:barlow64`, `font:plex18` and `font:label`;
  `LICENSES/OFL-1.1.txt` and the `THIRD_PARTY_NOTICES` section name the three families and their
  copyright holders.
- **The image grew from 1,811,808 B to 1,966,048 B (+154,240 B)**, of which 134,738 B is glyph
  data; it still fits the 4 MB app partition with room.
- `label_fonts.h` (generated by the packer) and the app's `k_label_font[]` agree index for index,
  so a missing face is a compile error. The Sunton build compiles all three with no warnings.
- The panel check - the numeral on the glass is Barlow Condensed, not Jura - is ticket 08's.
