# Design

Where a feature is worked: one directory per feature, one ticket per file, and the state on the
board rather than in the file ([`../agents/issue-tracker.md`](../agents/issue-tracker.md)).

Shipped features do not stay here. When one is accepted, its directory moves to
[`../archive/design/`](../archive/design/), so this folder holds live work only and the reasoning
of what shipped is kept one level away rather than deleted.
