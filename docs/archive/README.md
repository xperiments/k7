# Archive

Documents that are no longer true or no longer the source of truth, kept because their reasoning
is still part of the record. Nothing here is read by an agent unless it asks for it, and the
index in [`../README.md`](../README.md) does not list it.

A document arrives here when a newer document supersedes it, when the feature it described
shipped and the spec now owns the behaviour, or when it is a snapshot that has been overtaken.
It keeps its name and its status header, updated to `superseded` or `obsolete` and naming the
document that outranks it.

Move, don't rewrite: an archived document says what it said when it was written.
